Agent Outbox

Let AI agents draft your texts. Nothing sends until you approve it with Touch ID.

  1. Your agent drafts. Claude Code or any MCP client writes messages and personalised batches. It has no way to send.
  2. You approve. Read, edit or skip each one in the app, then approve with Touch ID.
  3. Your Mac sends. A small separate program checks your signature and sends through Messages.

Download

Download for Mac v0.1.0 · Apple silicon · macOS 14+ · Touch ID ·about 30 MB

  1. Open the DMG and drag Agent Outbox into Applications.
  2. Open it. It is free and not notarized by Apple, so macOS blocks the first launch: go to System Settings, Privacy & Security, click Open Anyway next to Agent Outbox and confirm.
  3. Click Connect Claude Code (or copy the command for another agent), then create your approval key with Touch ID.

Updates are new downloads from the same page, and macOS asks for Messages access again after each one. Agents connect to the app over MCP; it never lets them send.
