How it works

Draft. Review. Approve.

Your agent does the writing. You stay the one who presses send.

  1. 01
    outbox_create_batch

    Your agent drafts.

    Claude Code, Claude Desktop, Cursor or any MCP client writes single texts or personalised batches from a sheet or your contacts. It has no way to send them.

  2. 02

    You review in the app.

    Messages to the same person are bundled together, with warnings for unfilled fields, links and duplicates. Edit, skip or leave anything out.

  3. 03

    Approve with Touch ID.

    One touch signs exactly what you saw. A small separate sender checks that signature and sends through Messages, paced if you like.

Built to say no

Your messages.
Sent only by you.

Agent Outbox is a free Mac app with no server, no account and no browser page. Everything stays in one folder on your Mac.

  • ◉

    Touch ID, every time

    Approvals are signed by a key in your Mac's Secure Enclave. There is no password fallback, so nobody can approve over screen sharing.

  • ⌀

    Agents only draft

    The sender trusts nothing but your signature. A misbehaving agent can fill your inbox, never your recipients' phones.

First-time setup

Install and allow it to run.

Agent Outbox is free and isn't notarized by Apple, so macOS asks you to confirm it once. About two minutes.

  1. Move it to Applications

    Open the downloaded DMG and drag Agent Outbox into Applications.

  2. Open it, then allow it

    The first time, macOS says it can't verify the app. Click Done, then open System Settings › Privacy & Security, scroll down to “Agent Outbox was blocked” and click Open Anyway. Confirm with Touch ID.

    Prefer Terminal?

    This does the same for the app and its helpers in one go:

    xattr -dr com.apple.quarantine "/Applications/Agent Outbox.app"

  3. Let it work in the background

    Agent Outbox sends with a small background helper. If macOS shows “Background Items Added”, leave it on. If the app says the sender isn't running, turn on Agent Outbox in System Settings › General › Login Items & Extensions › Allow in the Background.

  4. Allow Contacts and Messages

    The first contact sync asks for Contacts, and the first send asks to control Messages. Click Allow on both. You can change either later in Privacy & Security.

  5. Set up Touch ID and connect your agent

    The app walks you through creating your approval key and has a one-click Connect Claude Code. For other agents it shows the MCP config to copy.

Questions

Good to know.

Can my agent send a message by itself?

No. Agents can only create drafts. The sender sends a message only when it carries your Touch ID signature over exactly that text and recipient.

Why does macOS block it the first time?

Apple's notarization needs a paid developer account. Agent Outbox is free, so it's signed on the machine that built it instead. The source is public, and each release lists a SHA-256 checksum you can verify.

Do I need Touch ID?

Yes: a Mac with Touch ID, or a Magic Keyboard with Touch ID. There's no password fallback, on purpose.

Which agents work with it?

Claude Code connects in one click. Claude Desktop, Cursor and any other MCP client work with the config the app shows. There's also a command-line tool.

Where is my data?

In ~/Library/Application Support/agent-outbox on your Mac. Nothing goes anywhere except the messages you approve, which go out through Messages.

How do I uninstall it?

Quit the app, delete it from Applications and delete the folder above. Turn it off under Login Items if it's still listed.
